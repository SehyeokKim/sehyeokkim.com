# 0007. 도메인 등록은 관리 계정, DNS는 워크로드 계정

- 상태: 채택
- 날짜: 2026-10-16

## 배경

- `sehyeokkim.com`을 Route 53 Domains로 등록했습니다. 등록은 결제를 담당하는 관리 계정에서 했고, 이때 관리 계정에 호스팅 영역이 자동으로 만들어졌습니다.
- 사이트 리소스(S3 · CloudFront)는 워크로드 계정에 있고, Terraform도 워크로드 계정만 대상으로 합니다(`allowed_account_ids`).
- CloudFront에 도메인을 붙이려면 ACM 인증서 검증 레코드와 별칭 레코드를 Terraform이 관리해야 합니다.

## 결정

**도메인 등록은 관리 계정에 두고, 호스팅 영역 · 인증서 · 레코드는 워크로드 계정에서 Terraform으로 관리합니다.** 두 계정은 네임서버(NS) 위임으로 연결합니다.

| 계정 | 두는 것 | 관리 방법 |
|---|---|---|
| 관리 계정 | 도메인 등록(결제 · 갱신 · 연락처 · 네임서버 설정) | 콘솔에서 사람이 직접. 네임서버는 처음 한 번만 설정 |
| 워크로드 계정 | 호스팅 영역, ACM 인증서(`us-east-1`), 별칭 레코드(루트 · `www`, A · AAAA) | `infra/modules/dns` |

- 호스팅 영역에는 `prevent_destroy`를 겁니다. 영역이 다시 만들어지면 네임서버가 바뀌어 도메인 전체가 끊기기 때문입니다.
- 인증서 DNS 검증은 위임이 끝나야 통과하므로 두 단계로 적용합니다. ① 영역만 만들기(`-var=attach_domain=false`) ② 관리 계정에서 네임서버 변경 ③ 인증서 · CloudFront 연결.
- `www.sehyeokkim.com`은 CloudFront Function에서 루트 도메인으로 301 리다이렉트합니다.
- 관리 계정에 자동으로 생긴 호스팅 영역은 위임 후 사람이 삭제합니다.

## 대안

| 대안 | 채택하지 않은 이유 |
|---|---|
| 도메인을 워크로드 계정으로 이전 | 무료이고 한 계정에 모이지만, 도메인 결제 · 갱신은 결제 계정에 두는 편이 역할 분리에 맞습니다. 위임은 한 번만 설정하면 되므로 관리 부담도 거의 없습니다. |
| 관리 계정의 자동 생성 영역을 그대로 사용 | 워크로드 계정의 Terraform이 관리 계정에 레코드를 쓰려면 계정 간 IAM 역할이 필요합니다. 관리 계정에 쓰기 권한을 여는 것은 피해야 합니다. |
| 기존 영역을 `data` 소스로 참조 | 영역이 관리 계정에 있어 워크로드 계정에서 읽을 수 없습니다. |

## 결과

- Terraform은 워크로드 계정 안에서만 동작하고, 관리 계정에는 사람이 콘솔로 하는 작업(네임서버 설정, 갱신)만 남습니다.
- 호스팅 영역 비용은 월 $0.50로 그대로입니다(관리 계정 영역을 지우고 워크로드 계정에 하나). 위임하는 달에는 두 영역 요금이 함께 청구될 수 있습니다.
- 워크로드 계정의 호스팅 영역을 지울 때는 `prevent_destroy`를 풀고, 관리 계정의 네임서버도 함께 바꿔야 합니다.
